# セツナとトワのはなうた（Webアプリ版）

刹那の気分を、永遠のはなうたに。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（キャラ画像も中に入っています） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色 |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `icons/` | ホーム画面用アイコン（iPhone用 180px、Android用 192/512px） |

このフォルダの中身を、まるごとWebに置けば公開できます。

## 公開のしかた

### いちばん簡単：Netlify Drop（数分・無料）
1. https://app.netlify.com/drop を開く
2. この `webapp` フォルダをページにドラッグ＆ドロップ
3. 発行されたURL（〜.netlify.app）をiPhoneのSafariで開く
4. 無料アカウントを作ると、URLが消えずに残り、名前も変えられます

### GitHub Pages（無料・更新管理しやすい）
1. GitHubで新しいリポジトリを作る（例：`hanauta`）
2. このフォルダの中身をアップロード
3. Settings → Pages → Branch を `main` / `root` にして Save
4. `https://<ユーザー名>.github.io/hanauta/` で公開されます

※ どちらも **https** で公開されるので、オフライン機能やホーム画面追加がそのまま動きます。
※ PCで `index.html` をダブルクリックして開いただけでは、オフライン機能は動きません（アプリ自体は動きます）。

## iPhoneでアプリにする
1. SafariでURLを開く（画面上部に案内が出ます）
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面の「はなうた」アイコンから起動すると、全画面のアプリとして動きます

一度開けば、そのあとは電波がなくても歌えます。

## 更新するとき
`index.html` などを差し替えたら、`sw.js` の `VERSION`（`hanauta-v1`）を `hanauta-v2` のように変えてからアップロードしてください。利用者のiPhoneに古い版が残り続けるのを防げます。
